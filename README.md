# Digital Display OCR

디지털 혈압계의 7세그먼트 숫자를 읽기 위한 **실험용 독립 도구**입니다. 외부 OCR API, 다운로드 모델, 서버가 필요 없습니다. 기존 원중약국 혈압 기록 앱과 별개이며 기록 앱에 아직 통합하지 않았습니다.

## 0.1.1 흑백 변환 개선

큰 LCD 획의 내부가 흰색으로 사라지는 문제를 수정했습니다. 배경 보정 반경을 이미지 짧은 변의 2.5%에서 12%로 넓혔습니다. 기본 조명 보정 외에 Otsu 전체 밝기 기준을 선택할 수 있습니다. 첨부 화면에서 추출한 숫자 영역으로 획 보존을 비교했으며, 실제 사진의 숫자 판독 정확도를 보장하는 변경은 아닙니다. 실제 사용자 사진은 저장소에 포함하지 않습니다.

## 바로 실행

[공개 도구 실행](https://azolazol.github.io/digital-display-ocr/)

압축을 풀고 **index.html**을 브라우저에서 엽니다. 이 파일에는 엔진과 시험 화면이 모두 포함돼 있어 인터넷 연결 없이 실행됩니다. 휴대폰에서는 GitHub Pages 등 HTTPS 정적 호스팅 사용을 권장합니다. 사진은 서버로 업로드하지 않으며 CSP의 `connect-src 'none'`으로 외부 연결을 차단합니다.

1. 사진을 선택합니다. 가능하면 혈압계를 직접 촬영한 원본 사진을 사용합니다.
2. ‘화면 전체 영역’을 선택한 뒤 숫자와 여백만 포함하도록 드래그합니다.
3. 분석 결과와 흑백 경계·숫자별 일치도를 확인합니다.
4. 자동 배치가 실패하면 수축기·이완기·맥박 줄을 각각 지정하고 ‘내가 지정한 세 줄 사용’을 선택합니다.
5. 특정 숫자가 어려우면 ‘등록할 숫자 하나’를 선택해 숫자 하나와 여백을 지정하고 정답을 등록합니다. 모양은 현재 브라우저에만 저장하며 JSON으로 백업할 수 있습니다.

## 원리

- 조명 차이를 줄이는 회색조 closing 배경 추정과 흑백 획 추출
- 숫자 행/열 투영으로 묶음과 자릿수 경계 추출
- 굵기·기울기가 다른 0~9 합성 템플릿 및 사용자가 등록한 32×48 템플릿과 IoU 비교
- 가장 잘 맞는 숫자와 차순위의 점수 차가 작으면 판독 보류
- 글자 높이가 비슷한 위·아래 두 묶음을 수축기·이완기, 그 아래 작은 묶음을 맥박으로 제안
- **숫자 값이 가장 큰 항목을 수축기로 정렬하지 않음**. 맥박 130, 수축기 110 같은 경우도 있으므로 위치와 글자 크기를 사용
- 수축기≤이완기이면 확인 요청. 숫자 값을 자동 교환하거나 범위에 맞춰 수정하지 않음
- 잘린 획·누락 줄·모호한 배치면 빈 값/확인 상태 반환

일치도는 템플릿과 겹치는 비율이며 정답률·의학적 신뢰도가 아닙니다. 분석 후보를 실제 기록으로 사용하기 전 원본과 비교해야 합니다.

## 재사용 API

`src/engine.js`는 DOM이나 네트워크를 사용하지 않는 ES 모듈입니다.

```js
import { recognizeDisplay } from './src/engine.js';
const result = recognizeDisplay(imageData, {
  sensitivity: 0.82,
  roi: {x: 20, y: 20, width: 260, height: 250},
  // 필요할 때만 fieldRois: {sys: {...}, dia: {...}, pulse: {...}}
});
console.log(result.sys, result.dia, result.pulse, result.status);
```

입력은 `{width, height, data}` RGBA(최대 400만 픽셀)입니다. `status`는 `candidate`, `incomplete`, `ambiguous`, `review` 중 하나입니다. `candidates`에 경계, 각 자릿수, 상위 3개 모양, 일치도, 판독 보류 이유가 포함됩니다. `mask`는 디버깅용 흑백 Uint8Array입니다.

## 개발·검증

Node.js 20 이상 권장. 외부 패키지 설치 불필요.

```sh
npm test
npm run build
```

- 0~9 모양 비교, 합성 화면 107/81/80의 세 줄 구분, 명시한 줄 보존, 잘린 숫자 거부, 빈 화면 거부, 상충 템플릿 보류 등 **25개 검사 통과**
- 브라우저에서 합성 예시 읽기와 숫자 0의 사용자 템플릿 등록 확인
- 합성 테스트는 같은 도형 계열을 사용하므로 실제 혈압계 정확도를 입증하지 않음
- 첨부된 앱 화면 캡처는 사진 상단이 잘려 있어 원본 수축기 전체가 보이지 않음. 실제 사진에서 101/107 같은 오독 해결이나 범용 정확도 향상을 검증한 버전이 아님
- 현재 자동 기울기/원근 보정 미지원. 크게 기울어진 사진은 정면으로 다시 촬영하거나 회전 후 영역 선택
- 기기별 숫자 폰트와 배치 차이, 1/7 및 0/8의 약한 획, 반사·저해상도가 주요 남은 과제
